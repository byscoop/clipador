Clipador

O Clipador é um aplicativo de uso pessoal, executado no computador do próprio criador de conteúdo, que transforma lives e vídeos longos em clipes verticais curtos. Ele transcreve o áudio, sugere os melhores trechos, adiciona legendas e permite que o criador envie os clipes para a própria conta do TikTok como rascunho (caixa de entrada) ou publicação.

Clipador is a personal desktop tool that turns long live streams and videos into short vertical clips. It transcribes audio, suggests highlights, adds captions and lets the creator upload the clips to their own TikTok account as drafts (inbox) or posts, using the TikTok Content Posting API.

Como usa o TikTok

  • Login Kit (user.info.basic): identificar a conta conectada e mostrar o nome dela no app.
  • Content Posting API (video.upload, video.publish): enviar os clipes que o próprio usuário escolheu e revisou para a conta dele.

Nenhum vídeo é publicado sem a ação explícita do usuário.
