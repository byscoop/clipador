Política de Privacidade

Última atualização: 18 de novembro de 2026.

1. Onde os dados ficam

O Clipador roda inteiramente no computador do usuário. Não há servidor do Clipador: vídeos, transcrições, configurações e tokens de acesso ficam armazenados apenas localmente, na pasta do aplicativo.

2. Dados do TikTok

Ao conectar a conta do TikTok, o app recebe um token de acesso e o nome de exibição/avatar da conta (escopo user.info.basic), usados somente para mostrar qual conta está conectada e para enviar os vídeos escolhidos pelo usuário (escopos video.upload e video.publish). Esses dados não são vendidos, compartilhados nem enviados a terceiros.

3. Dados do YouTube (Google)

Ao conectar a conta do YouTube, o app recebe um token de acesso do Google com os escopos youtube.upload (para enviar os vídeos que o usuário escolher) e youtube.readonly (só para mostrar o nome do canal conectado). O app não lê, altera nem apaga outros vídeos, comentários ou dados do canal. O token fica salvo apenas no computador do usuário e não é compartilhado com terceiros. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O Clipador usa os Serviços de API do YouTube; veja também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

4. Serviços de terceiros

Para sugerir os melhores trechos, o texto da transcrição pode ser enviado à API da Anthropic (Claude), conforme a política de privacidade da Anthropic. Os vídeos são enviados ao TikTok ou ao YouTube somente quando o usuário clica em enviar.

5. Exclusão

O usuário pode apagar todos os dados a qualquer momento excluindo os vídeos no app ou a pasta data, e pode revogar o acesso em TikTok > Configurações e privacidade > Segurança > Apps e serviços, e no Google em myaccount.google.com/permissions (ou pelo botão "desconectar" nas Configurações do app).
